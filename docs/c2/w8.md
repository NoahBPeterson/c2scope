# w8: retail bytes -> compilable C++ (the residual emitter)

Wave 8 targets spore-decomp's residual: the 4,020 functions with no source at all
(`tools/ci/fingerprints.jsonl` minus every manifest / nonmatching / partial / shape_only row).
The corpus is dominated by small leaves: 1,024 are <= 64 B, 2,565 are 65-256 B; 682 make no calls.
Almost all are /O2 esp-frame code (240 keep `ebp`).

The route is mechanical: no names, no types beyond what operand widths imply, no AI in the loop.
Every emitted function is compiled at the slice flags (`/O2 /MD /Gy /TP /EHsc`) and scored against
retail with the CI's own rule, so a MATCH is a slice that passes CI.

## The tools

| tool | what it does |
|---|---|
| `w8_lift.py`, `w8_batch.py` | lift retail bytes to `lift.py` tokens; corpus profile (token mix, size bands, call density). 87% of the corpus uses only emitter-supported constructs. |
| `w8_emit.py` | the emitter. capstone (32-bit) -> frame recovery (`[ebp-d]`/`[esp+d]` locals, `[ebp+d]` params, types from widths) -> per-register symbolic expressions (folded statements, memory writes in program order) -> flags pairing (`cmp`/`test`/arith + jcc) and single-exit forward branches as `if` blocks, `goto` otherwise -> a TU with `g_<va>` globals and `FUN_<va>` callees. |
| `w8_score.py` | compile + compare under the reloc mask (PE base relocs on retail, COFF relocs on ours), and the fingerprint.py::check audit (retail fixups covered by our relocations). MATCH == CI-safe. |
| `w8_stats.py` | batch metrics that catch a dropped body: `osz/size`, instruction alignment `ins%`, `bdiff`. |
| `w8_diff.py` | side-by-side disassembly from the first differing byte (needs `/Z7` for symbol lengths: `coff.parse_coff(..., sizes=True)`). |
| `w8_probe.py` | score one hand-written candidate against retail (the variant-search loop for deciding an emitter rule). |
| `w8_slice.py` | copy matched VAs into spore-decomp as `match/slices/s<va>/`. |
| `w8_emit64.py` | the x64 (cl 17.00) counterpart: one statement per instruction, the ceiling measurement. |

## Measured (2026-11-25)

- Full corpus: 4,020/4,020 compile, 62 MATCH under the strict audit; 46 merged in spore-decomp
  (#619, #620). Import thunks and open-source-library functions (`tools/site/modules.json`) are
  never sliced.
- Tier 0 (687 zero-call functions), batch v7: 71 MATCH / 616 DIFF / 0 CL-ERROR, median bdiff 34.
- Rules that moved matches, each found by diffing the nearest misses: `ret N` pads the declared
  args to `ret_pop/4`; `movsx` from a param slot makes it signed; a `setcc`-fed byte write to eax
  is a `bool` return; constant rotates as `(x<<n)|(x>>(32-n))` (c2 folds them to `rol`/`ror`);
  `xor ecx,ecx` and prologue `push ecx` are not reads of `ecx` (no phantom `__fastcall`); an ST0
  live at `ret` is a float return (else the body is DCE'd); `comiss`+`jbe` is `!(a > b)`.

## Open (by measured population in the tier-0 DIFFs)

- ~95 xmm functions: float/double arguments and SSE-typed callees.
- ~29 x87 statement functions (faddp chains), 19 `lock xadd` (intrinsics), 31 `rcl`/`rcr`.
- `shld`/`shrd` (306 hits): both probes say c2 lowers 64-bit shifts to shr/shl/or here.
- ~8 entries are tail fragments, not functions.

## The benchmark (`corpus.py`, `lbench.py`; 2026-11-25)

A **corpus** (`tools/corpus.py`, `work/corpus/<name>.jsonl`) describes one program: its image, and per function the
size, status (matched / equivalent / nonmatching / partial / residual), compiler build, flags, known source, and the
CI mask and fixups. The mask is computed from the image with spore-decomp's fingerprint rule (`Image.mask`; identical
to Spore's fingerprints on 2,000 of 2,000 sampled functions), so a program without fingerprints gets the same check.
Adapters: `spore` (manifests in match/ and src/game/, synth, clones; open-source runs dropped), `mb` (Ghidra index,
sized to the next start), `fnv` (fnv_decomp's units.json; needs the game's executable).

`tools/lbench.py run CORPUS` lifts a deterministic per-status sample, compiles each function with its own build
(one process per C2_BUILD) and flags, and scores it with the corpus's mask; `compare A B` gives gained and lost
matches on the same set (`--same-as`). The 46 functions of spore-decomp #619/#620 score 46/46 MATCH.

**Matched functions are ground truth**: a matching source exists, so every DIFF there is the lifter's shortfall.

Baseline, lifter 55ffa34f15f0, 300 per status:

| corpus | matched | nonmatching | residual | equivalent | partial |
|---|---|---|---|---|---|
| Spore (15.00) | 99 / 300 (33%), med ins 67% | 1 | 8 | 1 | 1 |
| Mount & Blade (13.10.3052) | 22 / 300 (7%), med ins 49% | 0 | 19 | - | - |

Spore's matched share is high because 46,604 of its 67,309 matched functions are 64 bytes or less (initializers,
getters); Mount & Blade's 7% is closer to the lifter's real reach. About 15% of DIFFs compile to under half the
original's size (a value or store lost: meaning bugs, not codegen).

The `w8_residual.json` list counted src/game's manifests as no-source: 2,928 of its 3,712 are matched there, and 11 of
the 46 merged lifted functions duplicate an existing match. Spore's real residual is 773 functions.

### Ground truth checked, and what separates misses from a match (2026-11-25)

`lbench.py run --task src` compiles each function's own source instead of the lifter's unit. On the band samples the
corpora's real sources reproduce: Fallout 3 (f3_decomp, cl 14.00) 400/400 (2 only by the naming rule: an address written
as a number), Mount & Blade 310/310 real functions (4 index entries are not functions), Spore 398/400. Scorer fixes this
needed: SECREL relocations (thread-local offsets) are masked, not "stray"; an image without .reloc (Mount & Blade)
takes our address-table relocations where retail's dword is an image address; Spore symbols resolve by run_all.py's
substring rule and, for rows without a manifest line, by slice.find_symbol (`spore_resolve.py`, a separate process).

`diffclass.py` sorts a miss into nonmatching.txt's causes from the two instruction streams: regalloc, frame,
schedule, copies (only moves/pushes/pops/lea differ: the allocator's footprint), structure, lost (under half size).

| sample | structure | lost | schedule | copies | regalloc | frame |
|---|---|---|---|---|---|---|
| lifted, matched functions (F3 + M&B + Spore, 1,114) | 825 | 154 | 5 | - | 1 | 2 |
| Spore nonmatching sources (285 DIFF) | 229 | 14 | 15 | 20 | 1 | 5 |
| Spore equivalent sources (216 DIFF) | 108 | 3 | 70 | 20 | 12 | 3 |

So the lifter's misses are structure (another computation), and the register/frame/schedule search is the next step
only for written sources: about a quarter of Spore's open sources, half of the equivalent ones.

### Step 2: meaning rules (2026-11-25, vs2005-cpp-ac)

`w8_short.py` sorts short outputs (under half retail's size) by the first lost effect: stores, calls, the
return value, branches or loads, plus `body-gone` when ours is 3 instructions or fewer. Six rules followed:

1. A `return` sits at its own `ret`. All of them used to render after the last label, so an early return ran on
   every path and c2 deleted the code behind it (0086aeb0).
2. At a jump target nothing falls into, the registers and the x87 stack are what the branches carried. They used to
   be what the linear scan left from the path above (0092ea70). After `test r,r; je L`, r is 0 at L (008773b0).
3. `or r,-1` / `and r,0` are the constants -1 / 0 (00946900).
4. A call with ecx written since the previous call and no caller cleanup is a `__thiscall`. It becomes
   `((C_<va>*)(ecx))->FUN_<va>(args)` on a stand-in struct, with one fixed-arity member per argument count.
   2,834 of the 3,712 functions on the list make such a call.
5. A call whose result the next x87 instruction reads returns `float` (00d1dd70). An x87 value left at `ret` is
   the return, whatever eax holds (00805200).
6. Before a store to memory, a register holding a memory read is fixed in a temp, and the store uses that temp.
   Otherwise the read happened after the store (00de52d0).

On the 3,712 list: MATCH 38 -> 58 (none lost), short 417 -> 297, and loop-free mean instruction alignment
57.0 -> 62.0% (1,250 better, 448 worse). 17 of the 20 new matches turned out to be already matched under src/game
(the residual caveat above), so only 3 were new (spore-decomp #622).

**Measure with ins% or bdiff + |size gap|, not bdiff alone.** bdiff counts only the shorter length, so a wrong
short output scores better than a right full-length one.

**Set aside as their own families:**
- `/Od` code compiled at /O2: 154 functions, an `/Od` emitter mode;
- loops: 1,104 functions; nothing carries a register across a back edge, so changes inside them are noise;
- 011cfd50: `push; call; pop ecx; ret` without a tail jump; 12 spellings and flag sets did not reproduce it.

### The IL route's ceiling (`lbench --task il2c`, 2026-11-25)

The real source's IL at Lower's entry, written back by il2c.emit_unit, compiled at the real flags and scored: the best
any bytes -> IL -> C++ route can do with il2c as it is. Same functions as w8_emit's e1c5 runs.

| program | il2c MATCH | emitted and compiled | UNSUPPORTED | w8_emit MATCH | both | union |
|---|---|---|---|---|---|---|
| Fallout 3 (400) | 18 | 28 | 354 | 32 | 11 | 39 |
| Mount & Blade (314) | 36 | 61 | 249 | 26 | 13 | 49 |
| Spore (400) | 41 | 73 | 321 | 58 | 23 | 76 |

When il2c emits, 56-64% match (its documented 70%); it declines 80-90%. Reasons over the three samples: address-taken
local 147, constructor/destructor/operator call 61, OPMBASSIGN (struct copy) 47, string-literal address 42+,
OPSWITCH 31, argument count 25+, OPPUSHSTATE (EH state) 22, OPINLINEARGS 21, vtable address 20, OPINTRINSIC 20,
OPSIDEEFFECT 17, jmp tuple 17. The two routes match different functions: the union is 22-88% above either alone.

Correction (same day): il2c's declines on real IL are mostly source-level constructs (address-taken locals, object
calls, struct copies, literal and vtable addresses) that IL lifted from machine code does not contain, so the table
above bounds the real-IL route, not a lifted-IL one. `lbench --task lift2il` (il2c_lift.unit, c1a1ace) on the same
functions:

| program | lift2il MATCH | lift2il only | union of the three routes | top declines |
|---|---|---|---|---|
| Fallout 3 (400) | 39 | 18 | 57 | fs: (EH frame / TLS) 101, x87 fld/fldz/fstp 91, switch jmp 11, sbb 9 |
| Mount & Blade (314) | 26 | 4 | 53 | x87 43, fs: 21, rep movsd 19, OPMUL 17, switch jmp 11 |
| Spore (400) | 36 | 7 | 83 | SSE movss/xorps 84, x87 22, rep movsd 22, switch jmp 19, sbb 12, cdq/div 22 |

lift2il's matches are all but three 64 bytes or less.
